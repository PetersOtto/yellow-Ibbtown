26/04/16 v0.9.5
===============
1) Some bugs fixed in:
 - _footer001.scss, _error001.scss, _markdown.scss
2) Create a override file for the edit extension.
   My goal was to create a consistent look and feel for the editor that appears the same
   in all themes, developed using the ibbtown theme. (https://github.com/PetersOtto/yellow-EditOverwrites)

26/04/03 v0.9.4
===============
1) Change from rule »@import« to rule »@use«.
 - look: https://sass-lang.com/documentation/breaking-changes/import/
2) Darken() and lighten() are no longer allowed.
 - look: _pagination001.scss --> $pagination-disable-color
 - look: https://sass-lang.com/documentation/breaking-changes/color-functions/
3) Due to the switch to »@use«, it was necessary to replace some »@extend« rules with »@mixin«.


26/02/09 v0.9.3
===============
1) »system/themes/theme.css« is not longer necessary.
 - look: enumeratetheme.php
 - look: https://github.com/datenstrom/community/discussions/1060#discussioncomment-15736839

26/02/04 v0.9.2
===============
1) Some bugs fixed
2) The tagnavi extension is now installed as a standalone extension. 
3) The filter name »All Projects« can now be changed in the »yellow-system.ini«.
